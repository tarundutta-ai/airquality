# AI Camera-Based Air Quality Detection System

Technology:
1. python
2. OpenCv
3. computer
4. ai-quality sensor


The way it is thought user will open its application, may be mobile camera, towards the sky (ofcourse it should not have any thing behind the air. Any visible object, like wall or something may create wrong calculations)

As of now we can detect
1. visible haze
2. smoke
3. dust
4. visibility


This will be a visible air pollution estimation, not AQI (Air Quality Index), or PM2.5
